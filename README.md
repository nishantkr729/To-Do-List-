# To-Do List - TaskFlow

Free to-do & notes app with glass dashboard, Today/Week/Month/Total filter, Abort (doesn't count), Need Extra Day (moves to next day + notification), Focus timer, Notes, Export CSV.

## Live (GitHub Pages)
Enable: Repo Settings > Pages > Deploy from branch > main / root > Save
Then open: https://nishantkr729.github.io/To-Do-List-/

## Data
Seeded with 367 tasks from Task_List_2026.xlsx (9 Sep - 24 Oct 2026). 73.4% completed excluding Abort.
New tasks save in browser localStorage. Export CSV for backup.

## Files
- index.html - complete app in one file, no build, no backend, no cost
